# 개선 백로그 (자율 루프가 유지·갱신)

각 항목: **[위험도]** `auto`(명백히 안전 → 자동 진행 가능) · `ask`(판단 필요 → 승인 후) · **우선순위** P1>P2>P3 · 상태 `제안|승인|진행|완료|보류`.
자율 루프는 `auto`+승인된 항목만 실행하고, `ask`는 여기 문서로 제안만 한다. 사람이 상태를 `승인`으로 바꾸면 다음 사이클에 진행.

> 갱신: 2026-06-27 (초기 판단)

---

## A. 안정성·데이터 무결성 (먼저)
- **A1** `[auto]` **P1** 외부(Commons) 사진을 자체 호스팅으로 미러링 — 위키 측 파일 삭제/이동 시 404 방지. `/portraits`로 받아 PHOTOS 경로 교체. 상태: `완료`(2026-06-27) — 외부 사진 20장 미러링, photos.ts 전부 로컬 경로(외부 http 0), DB 재시드
- **A2** `[auto]` **P2** 이미지 로드 실패 폴백(onError). 상태: `완료`(2026-06-27)
- **A3** `[ask]` **P2** 묘역 인원수 일관성 점검을 health-check에 추가(내러티브/좌측/상세 카운트 == roster+extra). 상태: `완료`(2026-06-27) — 명단 보유 묘역의 출처·총원 설명 존재, 각 안장자 이름(한/영)·행적 필드 검증 추가

## B. 데이터·콘텐츠 보강
- **B1** `[ask]` **P1** 양화진 안장자 명단 확대(현재 주요 13명) — 공식 묘원 명단 기반 추가. 상태: `완료`(2026-06-27) — 검증된 11명 추가(13→24): 켄드릭·페인·모리스·채핀 부부·소다 가이치·최봉인·피터스 두 부인·졸리·도익서. 셔우드 홀은 기존 인물카드라 제외
- **B2** `[ask]` **P2** 유적지 좌표 근사치(`coordUncertain`) 다수 → 네이버/카카오 기준 정밀 보정. 상태: `완료`(2026-06-27) — 출처 검증된 21곳 보정·근사치 해제 19곳(교산교회 오류 좌표 수정 포함). 건물 단위 미확정 5곳(안동교회·송천예배당·조지와츠관·공주 선교사가옥·제주 영흥학교)과 북한 6곳, 거리/도로 단위 2곳은 근사치 유지
- **B3** `[ask]` **P2** 사진 없는 인물(유진 벨·오웬·벙커·변요한 등) PD 초상 추가 추적(HathiTrust *The Missionary* 등). 상태: `제안`
- **B4** `[ask]` **P3** 인물 요약·연표 출처 보강(현재 일부만 출처). 상태: `제안`

## C. 기능
- **C1** `[ask]` **P1** 검색 자동완성(인물·유적·묘역 통합). 상태: `완료`(2026-06-27) — 검색 시 유적·묘역도 결과에 표시
- **C2** `[ask]` **P2** 헤더 네비 속도 — `force-dynamic` 대신 정적 + 클라이언트 오버레이로 전환(인물 클릭 시 서버 리페치 제거). 상태: `완료`(2026-06-27) — ISR(`revalidate=300`)로 전환, 클릭당 Supabase 왕복 제거. /admin 저장 시 `revalidatePath("/","layout")`로 즉시 반영
- **C3** `[ask]` **P2** 유적지 상세에 ‘관련 인물’ 외 ‘인근 묘역·거점’ 연결. 상태: `완료`(2026-06-27) — 유적 상세에 '인근 거점·유적' 섹션(거리순, 거점 ≤12km·유적 ≤6km, 클릭 이동)
- **C4** `[ask]` **P3** 영문(EN) 토글 — 해외 연구자·후손 접근성. 상태: `제안`
- **C5** `[ask]` **P3** 공유/딥링크 — 현재 보고 있는 상태(인물·묘역·연도)를 URL로 공유. 상태: `완료`(2026-06-27) — 상세 카드에 '공유' 버튼(인물·묘역·유적·안장자 + 스냅샷 연도를 URL로 복사). `?buried=` 딥링크 지원 추가
